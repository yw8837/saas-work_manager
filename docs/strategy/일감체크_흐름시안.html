일감

합성 예시 4건

    고객명·금액·일정·남은 횟수는 모두 설명용입니다.

    무엇을 맡기고, 어디서 멈추나

    두 흐름 모두 미구현 기획입니다. 이 파일은 화면 안에서만 상태를 바꾸며 외부 시스템에 접근하지 않습니다.

    승인된 사실 안내

    1. 고객이 이미 쓰는 채널에서 문의합니다.
    2. 고객·주문을 특정한 뒤 판매자가 승인한 패키지·주문 사실과 갱신 시각을 확인합니다.
    3. 범위가 확인된 답변만 같은 채널로 안내하는 흐름을 검증합니다. 일정 변경·새 가격·수정 수락을 임의로 약속하지 않습니다.
    4. 주문이 여럿이거나 근거가 없으면 답변을 멈추고 사람에게 넘깁니다. FAQ 안내는 수정 횟수를 차감하지 않습니다.

    요청 수락부터 작업 결과 안내까지

    1. 수정 요청을 받되 접수만으로는 차감하지 않습니다. 판매자가 연결 주문·범위·남은 횟수·생성할 할 일을 보고 명시적으로 수락하면 할 일 생성과 1회 차감을 한 번만 반영합니다.
    2. 동일 채널로 수락 결과를 안내합니다. 문의·추가 범위·미승인은 차감하지 않습니다.
    3. 작업자가 내부에서 완료해도 고객에게 바로 공개하지 않습니다. 판매자가 고객 공개용 파일과 고객에게 알릴 상태를 따로 선택하고 명시적으로 확정합니다.
    4. 확정한 파일·상태에 근거한 결과 안내 초안을 검토한 뒤 같은 채널에 안내합니다. ‘납품 완료 안내’는 고객 검수·인수 동의로 처리하지 않습니다.
    5. 전송 실패는 별도로 남기고 재시도하며 수락·공개·차감을 반복하지 않습니다. 납품물 공개와 결과 안내 자체의 추가 차감은 0회입니다.

    채널별 실제 경계

    기존 채널 이용 여부가 파일럿 조건입니다. 모든 고객에게 새 채널 이동을 요구하지 않는다고 확정할 수 없습니다.

    접점이 시안의 취급
    카카오톡 채널기존 채널 연동 후보. 계약·권한·고객 식별·발송 조건·비용과 실제 왕복 검증 전입니다. 연결 버튼은 모의 상태만 바꿉니다.
    개인 카카오톡일반 대화 자동 수발신 미지원. 연결·자동 답변 버튼을 제공하지 않습니다.
    크몽외부 메시지 수신·답장 공개 권한 경로 미확인. 크몽 자체 자동응답을 외부 연동 기능으로 표현하지 않습니다.
    고객 포털현재 제품의 수정요청 링크를 이용하는 수동 대안입니다. 기존 채널 자동 응대와 동일한 가치로 보지 않습니다.
