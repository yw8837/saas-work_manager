# 일감체크 빠른 초안 MVP 구현 감사

> 기준 문서: `prompts/00_MVP_DRAFT_MASTER.md`만 실행 기준으로 사용했다. 이 문서는 2026-08-15 현재 `01_일감체크/app`의 실제 코드 상태를 기록하며, 구현 후 검증 결과는 별도 산출물에 남긴다.

## 현재 구현

| 영역 | 확인된 구현 | 판정 |
|---|---|---|
| 기술 기반 | Next.js + TypeScript, 모바일 PWA manifest/service worker, Vitest, Playwright가 구성되어 있다. | 유지 |
| 자동합성 도메인 | `composeJob`이 패키지·옵션의 금액, 예상원가, 기간, 수정 한도, Todo 추가/제거, 상대기한을 순수 함수로 합성한다. 중복 옵션·Todo 키도 검증한다. | 유지·확장 |
| 일감 스냅샷 | 생성 시 패키지/옵션을 깊게 복사하여 이후 템플릿 변경과 기존 일감을 분리한다. | 유지 |
| 수정 기록 | 고객 링크와 수동 기록이 `recordRevision` 단일 경로를 사용하고, 초과 요청 원문을 `추가 작업 검토`로 보존한다. | 유지·확장 |
| 로컬 데모 | localStorage 저장·복원, 같은 브라우저의 고객 수정요청 경로, 탭 간 동기화 기반이 있다. | 유지 |
| Today | 기한이 지난/오늘 Todo의 빠른 완료, 고객 대기, 연락/작업 링크 바로 열기, 일감 완료가 있다. | 유지·실데이터 보강 |
| Supabase 경계 | migration, RLS, 공개 수정요청 RPC 초안이 있다. 실제 키·Auth 연결은 없다. | 보존·정합성 확인 |

## 누락 또는 불완전한 항목

| 요구 | 현재 상태 | 구현 방향 |
|---|---|---|
| Basic/Standard/Deluxe 홈페이지 제작 패키지 | 베이직 홈페이지와 프리미엄 쇼핑몰 2종만 있다. | 3종 홈페이지 패키지와 옵션을 기본 카탈로그로 교체한다. |
| 패키지 편집 화면 | 탐색 메뉴가 비활성화되어 있고 라우트가 없다. | 실제 CRUD형 로컬 카탈로그 편집 화면과 저장을 추가한다. |
| 옵션 편집 | 새 일감 화면의 추가 버튼이 비활성화되어 있다. | 패키지 화면에서 옵션의 금액·기간·수정·Todo 변화 편집을 제공한다. |
| 일감 링크 저장 | 기존 링크는 표시/열기만 하며 상세에서 추가·수정할 수 없다. | 카카오·디스코드·작업 사이트·Figma·Drive 링크 저장/즉시 열기를 추가한다. |
| 추가요청 확정 | Addon 타입과 Supabase 테이블 기반은 있지만 로컬 UI/상태 변경이 없다. | 내용·금액·기간·Todo를 기록하고 확정 시 합계/마감/Todo에 반영한다. |
| 인앱 알림 | 브라우저 테스트 helper는 있지만 Today·설정·알림함과 연결되지 않았다. | 마감 D-2/D-1/당일/지연, 고객대기 2/5일, 새 수정요청 알림 큐·설정·테스트 알림을 연결한다. |
| 고객 링크 문구 | 같은 브라우저 데모는 동작하지만 상세 문구가 다음 단계 연결로만 표현된다. | `로컬 데모` 및 실제 외부 공개 링크의 `BLOCKED_EXTERNAL` 경계를 명시한다. |
| 고정 카피 | Today의 잡일 브리핑이 특정 고객명을 하드코딩한다. | 상태에서 계산한 실제 알림 문구로 교체한다. |

## 확인된 충돌과 해소 원칙

| 항목 | 충돌 | 해소 원칙 |
|---|---|---|
| 기존 도메인 계산 | UI에서 별도 계산을 추가하면 결과 불일치 위험이 있다. | 모든 미리보기·생성·추가요청 확정은 순수 도메인 함수를 호출한다. |
| 후속 서버 범위 | 실제 Supabase 키·Auth·공개 외부 링크·예약 Web Push는 이 초안에서 검증할 수 없다. | 코드 경계와 migration은 남기되 `BLOCKED_EXTERNAL`로 정확히 표시한다. |
| 패키지 편집과 일감 보존 | 템플릿을 바꾸면 기존 주문 조건이 바뀌면 안 된다. | 이미 있는 스냅샷 원칙을 유지하며 새 일감에만 현재 템플릿을 적용한다. |
| 알림의 신뢰성 | 열린 탭의 타이머와 실제 예약 푸시는 동등하지 않다. | 인앱 큐와 사용자 클릭 기반 브라우저 테스트만 구현하고, 백그라운드 전달은 차단 항목으로 둔다. |

## 이번 구현의 완료 기준

이번 초안은 실제 로컬 브라우저에서 패키지·옵션 선택부터 자동합성, Today 처리, 링크 저장, 양쪽 수정요청 기록, 추가요청 확정, 인앱 알림 확인까지 클릭으로 검증한다. Supabase의 실제 연결과 외부 기기용 공개 URL, 예약 Web Push 전송은 구현 완료로 표기하지 않는다.
