## Baseline findings

- FINDING-001: An empty Today screen shows summary counters, priority, waiting and deadline cards before an obvious starting path. Replace this only when there are no jobs.
- FINDING-002: Mobile inputs use 14px type; many work labels are 10–11px. Improve legibility and touch sizes within existing layouts.
- FINDING-003: Package list occupies a separate vertically scrolling 220px panel above the editor on mobile. Provide a compact horizontal chooser.
- FINDING-004: The full-width amber survey competes with the main workflow. Retain its content and destination but lower visual emphasis.
- FINDING-005: Landing preview autoplays with only hover/focus pauses, no explicit pause, and small dot targets. Respect reduced motion and add a persistent toggle.
