# 일감체크 서비스·고객검증 실행 패키지

기준일: 2026-10-25. 범위는 전략·설계·공개 업체 조사·로컬 설명용 시안이다. 운영 기능 개발, 계정 연결, 발송, 신청, 결제, 배포는 제외한다.

## 완료 기준

- SCQA에서 반복 외주의 관리·응대 문제, 기존 경쟁 대안의 기능, 차별화 가설을 구분한다.
- 크몽 외 직접·소개·자사 사이트·SNS 수주 고객으로 확장한다. 채널 연동 파일럿과 전체 시장 모집군을 분리한다.
- 현재 패키지·일감 MVP와 미구현 고객 CS 계획을 표시한다. 2개 핵심 기능, 정상/예외/실패 흐름과 모바일 UX를 설계한다.
- 100만원 AI 지원금으로 구매할 수 있는 등록 상품과 별도 견적/미등록 업체를 분리한다. VAT·매체비·운영자·계정 권한·기간을 확인한다. 불가능한 조합을 확정 구매안으로 만들지 않는다.
- 모집 기준·중립 설문·인터뷰·순절감 측정·광고 브리프·지표·실행 순서를 작성한다. 목표 수치는 실적과 구분한다.
- 설명용 HTML 문서와 클릭 가능한 합성 데이터 시안을 만든다. 서버/DB/브라우저 저장소에 고객 데이터를 쓰지 않는다.
- 윤문 전후 의미·수치 보존, 문서 링크, 예산 산술, 브라우저 가독성·접근성·예외 흐름을 검증하고 독립 리뷰 지적을 반영한다.
