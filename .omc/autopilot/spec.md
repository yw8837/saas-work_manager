# 일감체크 MVP 구현 명세

## 목표

기획 문서의 핵심 자동화 체인을 실제 브라우저에서 사용 가능한 MVP로 구현한다.

## 성공 시나리오

- 기본 패키지와 옵션 예시가 준비되어 있다.
- 사용자는 고객 별칭, 시작일, 패키지, 옵션을 입력해 60초 안에 일감을 만든다.
- 금액, 마감, 수정 한도, 옵션별 Todo가 결정론적으로 생성된다.
- Today와 일감 상세에서 완료/대기/수정 기록이 즉시 반영된다.
- 고객 수정요청 폼과 작업자 수동 기록이 같은 수정 로그·카운터를 사용한다.
- 새로고침 후에도 데이터가 유지된다.
- 모바일 390px와 데스크톱 1440px에서 핵심 흐름이 깨지지 않는다.

## 실행 방식

- 즉시 체험 가능한 단일 사용자 로컬 모드: 브라우저 localStorage 기반
- 배포용 데이터 계층: 동일 도메인 타입·저장소 인터페이스와 Supabase SQL 마이그레이션 제공
- Supabase 환경변수가 없으면 로컬 모드임을 명확히 표시
- 다른 기기에서 열리는 실제 고객 공개 링크와 서버 푸시는 Supabase 연결 후 활성화

## 기능 범위

- 반응형 랜딩/데모 진입
- Today, 일감, 패키지, 설정 내비게이션
- 패키지/옵션 CRUD
- 새 일감 자동합성
- 일감 상세·링크 허브·업무 상태 전환
- 수정 요청 자동/수동 기록과 잔여 횟수
- 추가 요청 기록과 금액 반영
- 로컬 알림 권한/브라우저 알림 테스트 및 앱 내 마감 큐
- PWA 설치 기반
- 단위 테스트와 핵심 브라우저 흐름 테스트

## 제외

- 결제 PG, 실제 구독 과금
- 외부 플랫폼 API/스크래핑
- 이메일·카카오 자동발송
- 완전한 회계/전자계약/파일 협업

## 완료 조건

- `npm run build`, `npm test`, 린트가 통과한다.
- 데스크톱/모바일 핵심 화면을 실제 브라우저로 확인한다.
- 자동합성, 옵션 순서 독립성, 수정 차감/초과, 저장 복원 테스트가 있다.
- README에 실행법, 로컬 모드 한계, Supabase 연결 절차가 있다.
