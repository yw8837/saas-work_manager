# 실행 순서

1. 공개 상품·경쟁 근거와 저장소의 구현 상태를 읽는다. 업체 조사와 전략/기술 검토를 분리한다.
2. 메인이 SCQA, 확장 경로, 2개 핵심 흐름, DB/서버 경계, 조사·광고 브리프를 통합한다.
3. 승인된 현행 중립 색상·체리 주의색을 재사용하는 독립 로컬 UX 시안을 작성한다. 기획 표시와 연결 불가 상태를 노출한다.
4. humanizer/content-humanizer로 기계적 문장을 진단한다. humanize-korean heavy 진단→윤문→재조립→게이트→finalize→게이트를 실행한다.
5. UltraQA에서 문서/예산과 시안 정상·미연결·복수 주문·중복 수락·전송 실패·주입 문자열·모바일·키보드를 확인한다. 최대5회, 동일실패3회 중단.
6. 기능/근거·안전·품질 독립 리뷰에서 발견한 결함을 수정한다. 명시 파일만 커밋·푸시하고 실제 Git 상태로 확인한다.

이번 런은 Windows 네이티브 도구로 수행한다. OMC 전용 모델·tmux 실행을 가장하지 않는다. 회사 컨텍스트 설정 파일이 없어 외부 컨텍스트 호출은 생략했다.
